# Social Network Backend System

A robust, scalable backend architecture for social networking data. This project emphasizes system stability, error handling, and automated quality assurance to ensure reliable data management under varied user inputs.

Designed as a reference implementation for backend logic, data integrity validation, and error handling in Python.

## Features
- User Management: Secure registration and authentication logic with type validation.
- Friendship Graph: Logic to handle friend requests, acceptances, and relationship mapping.
- Content Management: Systems for creating posts, commenting, and liking with duplicate prevention.
- System Observability: Integrated logging module to track critical system events, warnings, and errors for root cause analysis.
- Automated QA Suite: Full unittest coverage including happy-path validation and edge-case testing (negative testing).

## Technical Stack
- Language: Python 3.14.0
- Testing Framework: unittest (Standard Library)
- Logging: Python logging module (Info/Warning/Error levels)
- Data Structures: Dictionaries, Sets, Lists (In-Memory Storage)
